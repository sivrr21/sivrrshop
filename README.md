# ⚡ SVIRR SCRIPT • Hub Habbo

Site officiel moderne & minimalist **SVIRR SCRIPT** pour la communauté Habbo.
Design **Liquid Glass**, thème sombre / bleu nuit, ultra-fluide et **sans scroll**.

---

## 🌟 Fonctionnalités
- **Liquid Glassmorphism** : Reflets dynamiques réactifs au curseur, flou d'arrière-plan et orbes lumineux.
- **Zéro Scroll (100dvh)** : Interface verrouillée et parfaitement ajustée au viewport.
- **Navigation par Catégories** : 
  - **Accueil** : Logo animé, présentation épurée et bouton Discord interactif.
  - **À Propos** : Charte de transparence, scripts 100% gratuits & open-source, tolérance zéro contre la toxicité.
- **Raccourcis clavier** : Flèches gauche/droite (← / →) pour basculer rapidement entre les catégories.

---

## 🚀 Déploiement sur GitHub Pages

1. Créez un nouveau dépôt public sur votre compte GitHub (ex: `svirr-script`).
2. Déposez les fichiers à la racine du dépôt :
   - `index.html`
   - `styles.css`
   - `app.js`
   - `README.md`
3. Rendez-vous dans **Settings** > **Pages** > sélectionnez la branche `main` et le dossier `/ (root)`.
4. Votre site sera automatiquement en ligne sur `https://<votre-pseudo>.github.io/svirr-script/`.
